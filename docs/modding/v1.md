# What Still Works in `api.v1`

Part of [Exotic Worlds from Another Mod](../modding.md).

`com.exoticworlds.api.v1` is frozen. A mod built against it still loads, and most of it still works. The parts that no longer do anything carry the `@Broken` annotation, whose text says what stopped and what replaces it.

## What works

| Part | Types |
| --- | --- |
| Reading the geometry | `ExoticWorldsApi.shapeOf`, `ExoticWorldsClientApi.shapeOf`, `ToroidalShape`, `SeamShift` |
| Laps a player has traveled | `ExoticWorldsApi.travelOf` |
| Packets and particles | `PacketRewriters`, `ParticleRewriter`, `SeamContext` |
| Generation hooks | `GenerationHooks.atRandomState`, `GenerationHooks.atStructureStarts`, `StructureStarts` |
| Terrain outside the chunk map | `GenerationProbe`, `TerrainSnapshot` |
| Client anchors | `ClientAnchors` |
| Stored options | `WorldOption`, `WorldOptions`, `GenerationOptions` |
| Reading a world's spans | `LoopSpans`, `ShapeDimensions.spansOf`, `ShapeDimensions.optionsOf` |

`travelOf`, `GenerationProbe` and `ClientAnchors` have no `api.v2` form, so keep using them from here.

## What is broken

| Type | What stopped |
| --- | --- |
| `ShapeModule` | No screen lists a shape declared this way, so it is never chosen, applied or read back. |
| `ShapeCustomizers` | No screen shows a Customize button, so the customizer is never opened. |
| `WorldOptionControls`, `WorldOptionControl`, `WorldOptionContext` | No screen builds these controls, so a control registered for an option is never shown. |

Move a shape to [`ShapeV2`](shapes.md) and an option with its control to [`OptionFeatureV2`](features.md).

## A hook checks its own world

A `GenerationHooks` hook runs for every looping level of every world, whatever shape made it. Read `shape` and `options` and return early unless both are what the hook is for.

Read an option's value with the `WorldOption` instance that `WorldOptions.all()` holds, found by its key. An instance you build yourself with the same key but another position reads the default.

## From `api.v1` to `api.v2`

| `api.v1` | `api.v2` |
| --- | --- |
| `ExoticWorldsApi.shapeOf(level)` | `WorldGeometriesV2.of(level)` |
| `ExoticWorldsClientApi.shapeOf(...)` | `ClientGeometriesV2.of(...)` |
| `ToroidalShape` | `WorldGeometryV2` |
| `sqrDistance` | `sqrDistanceBlocks` |
| `boxesOverlap` | `areBoxesOverlapping` |
| `preservesLocalIndices()` | `areLocalIndicesPreserved()` |
| `foldCoord`, `foldBlock`, `foldChunk`, `nearestCoord`, `decomposesPerAxis()` | fold the whole position, read a bound from `getSpans()` |
| `Orientation.flipsX()`, `flipsZ()` | `applyToDelta(delta)`, `isIdentity()`, `isHandednessPreserved()` |
| `SeamShift`, `Oriented`, `Orientation` | `SeamShiftV2`, `OrientedV2`, `OrientationV2` |
| `PacketRewriters`, `ParticleRewriter`, `SeamContext` | `PacketRewritersV2`, `ParticleRewriterV2`, `SeamContextV2` |
| `GenerationHooks.atRandomState` | a feature that implements `RandomStateMomentV2` |
| `GenerationHooks.atStructureStarts` | a feature that implements `StructureStartsMomentV2` |
| `WorldOption` with a `WorldOptionControls` control | `OptionFeatureV2` |
| `ShapeModule` with a `ShapeCustomizers` screen | `ShapeV2` with its parameters |

A class registered for packet rewriting through both versions throws on the second registration, so move each class once.
